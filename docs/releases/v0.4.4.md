# DeX 主页 0.4.4（实验版）

独立的免 Root 三星 DeX 主页应用，包名 `com.alkaidlab.dexlocal`，versionCode 17。应用不依赖 Sunshine 运行。项目沿用原 Sunshine Android 代码的 GPL-3.0 许可，来源见 [NOTICE](../../NOTICE.md)。

## 功能

- 真正的三星原生 DeX 在手机内屏全屏显示，并作为默认 HOME 使用。
- 按手机 HOME 返回 DeX 桌面，最小化原生 DeX 窗口并保留应用任务。
- 去除主页上的设置悬浮按钮；从“DeX 主页”软件入口打开管理与设置。
- 通过三星任务栏最左侧应用菜单中的“退出 DeX”退出，恢复原手机主页及默认 HOME。
- 原生退出后接收服务继续待机。直接打开三星 DeX，重新连接 **DeX Home**，自动进入全屏桌面并切换默认 HOME。
- 备份并恢复本会话修改的 DeX 逻辑尺寸、主页选择和高刷实验设置。

## 使用条件

需要支持 **DeX for PC** 的三星固件、已连接的 Wi-Fi，以及已启动并授权的 Shizuku／Stellar shell 用户服务。应用运行时加载设备自己的 DeX 组件，不随 APK 或源码分发三星 APK、厂商原生库。

首次使用：连接权限服务 → 启动接收服务 → 打开三星 DeX → 选择 DeX Home 并确认 → 全屏预览 → 设为默认主页并进入。之后退出和重新连接可直接使用三星 DeX 的原生入口。

接收服务存活且网络条件满足时，退出后的目标保持待机。系统重启或权限服务停止后，可能需要重新启动权限服务并打开应用。退出结束本次 DeX 会话，不保证原会话的应用和窗口继续运行。

## 实机验证与限制

测试设备：Samsung S20+ SM-G986U1，Android 13 / One UI 5.1。最终 0.4.4 已验证 2400×1080 全屏、HOME 返回桌面、原生退出恢复主页，以及接收进程不重启时的再次发现和自动重连。

**“尝试 120Hz”目前没有解除这台设备的 60 帧限制。** 使用相同接收／合成后端测量的源应用实际绘制帧率：默认约 60.18 fps，请求 120Hz 后约 60.21 fps；DeX 和物理内屏的活动模式仍为 60Hz。帧率请求成功不代表实际刷新率或桌面帧率提升。完整过程及样本版本见 [验证记录](../HOME-2026-10-26.md)。

尚未验证其他机型、开机自动恢复、小时级连续运行及所有鼠标／键盘／输入法组合。应用依赖固件内部接口，兼容性以实机结果为准。

构建检查：13 项 JVM 测试通过，Lint 为 0 errors / 11 warnings，Release APK 签名校验通过。本实验版使用当前本机 Android debug key 签名；后续覆盖安装需要相同签名。
